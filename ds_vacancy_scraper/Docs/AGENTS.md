# Проект: DS Vacancy Scraper

## Описание проекта
Это пет-проект, созданный для усовершенствования навыков в области машинного обучения (Machine Learning) и Data Science. 
Проект представляет собой инструмент для сбора и анализа вакансий.

**Глобальная цель проекта:** Создание полноценного приложения, которое будет предоставлять актуальные вакансии с популярных сайтов для поиска работы. Собранная информация будет передаваться в ML-модель для анализа рынка труда и выявления наиболее востребованных навыков.

## Текущий функционал проекта
На данный момент проект выполняет следующие задачи:
* **Сбор данных (Web Scraping / API):** Скрипт scraper.py осуществляет поиск и парсинг вакансий по запросам "Data Science Intern" и "Data Science Junior".
* **Интеграция с источниками:** 
  * Habr Career (через скрытое API)
  * Remotive.com (через публичное API)
  * GeekJob.ru (парсинг HTML-страниц)
* **Извлечение признаков:** Извлекается ключевая информация о вакансиях (источник, название, компания, город, формат работы, требования/навыки, зарплата, ссылка на вакансию).
* **Сохранение данных:** Собранные и очищенные от дубликатов данные экспортируются в формат CSV (ds_junior_advanced.csv) для последующего анализа.

## План развития проекта (Roadmap)

Основываясь на целях проекта (интеграция ML и создание приложения), план дальнейших действий выглядит следующим образом:

### Этап 1: Улучшение сбора и обработки данных
1. **Расширение источников:** Добавление новых площадок (например, HeadHunter API, LinkedIn и др.).
2. **Улучшение парсера:** Добавление обработки пагинации (сбор более 1 страницы результатов), обход возможных блокировок (прокси, ротация User-Agent).
3. **Очистка данных (Data Cleaning):** Написание скрипта для нормализации зарплат (приведение к одной валюте, выделение минимальной и максимальной вилки) и стандартизации форматов работы.

### Этап 2: Machine Learning & NLP (Анализ навыков)
1. **Предобработка текста:** Токенизация и лемматизация описаний вакансий и требований.
2. **Извлечение сущностей (NER):** Использование библиотек NLP (например, spaCy, NLTK или предобученных моделей Hugging Face) для точного извлечения названий технологий и навыков из сырого текста вакансий, если они не указаны тегами.
3. **Аналитика рынка:** Подсчет частоты упоминаний навыков, корреляция навыков с предлагаемой зарплатой, кластеризация вакансий по грейдам.

### Этап 3: Создание приложения (Backend + Frontend)
1. **Разработка БД:** Переход от CSV к полноценной базе данных (SQLite / PostgreSQL) для хранения истории вакансий и отслеживания динамики рынка.
2. **Backend (API):** Создание сервиса на FastAPI или Flask для управления данными и запуска ML-модели по запросу.
3. **Frontend (UI):** Создание пользовательского интерфейса. Отличным вариантом для пет-проекта по ML будет **Streamlit** или **Dash** — они позволят быстро создать интерактивные дашборды (графики самых востребованных навыков, список свежих вакансий). Альтернатива: создание Telegram-бота.

### Этап 4: Автоматизация и Деплой
1. **Автоматизация сбора:** Настройка планировщика (Cron, Apache Airflow или Celery) для ежедневного запуска парсера и обновления базы.
2. **Контейнеризация:** Упаковка проекта, ML-модели и дашборда в Docker.
3. **Деплой:** Развертывание приложения на облачном сервере (VPS), чтобы к нему был постоянный доступ.
