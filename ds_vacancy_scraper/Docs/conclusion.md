# Итоговый вывод по пет-проекту

## 1. Сбор и подготовка данных (Data Engineering)
- Настроен парсинг данных из закрытых API. 
- Исходные данные прошли профессиональную очистку: удалены дубликаты, строковые финансовые значения переведены в числовые (числовой таргет `salary_num`), создан бинарный флаг формата работы (`is_remote`) и посчитано количество требований в вакансии (`req_len`).
- В учебных целях были сгенерированы синтетические зарплаты для вакансий, где они не указаны.

## 2. Разведочный анализ (EDA)
- Построены гистограммы распределения и матрицы корреляции. 
- Был обнаружен ключевой инсайт: так как зарплаты заполнялись с помощью `np.random` для демонстрации, корреляции между реальными требованиями (`req_len`) и синтетической зарплатой нет. Это идеальная иллюстрация для принципа *Garbage In, Garbage Out*.

## 3. Машинное обучение (Machine Learning)
Проект покрывает оба главных направления в классическом ML (Supervised Learning):

### А. Регрессия (Предсказание точной суммы)
- **Модели:** Линейная регрессия, Случайный лес (Регрессор).
- **Результат:** Из-за синтетической природы зарплат модель не нашла математической связи ($R^2$ ниже нуля). На реальных данных Линейная регрессия показала бы, сколько в рублях "стоит" на рынке каждый выученный навык из стека Intern/Junior.

### Б. Классификация (Предсказание категории)
- **Преобразование:** Целевой признак `salary_num` был разделен на 3 класса: `Low` (до 150к), `Medium` (150к - 220к) и `High` (от 220к).
- **Модели:** Случайный лес (Классификатор).
- **Результат:** Вместо попытки угадать зарплату с точностью до рубля, модель училась определять ценовой сегмент вакансии. Оценка производилась с помощью метрик `Accuracy` (доля верных ответов), `Precision` (точность) и `Recall` (полнота).
